TODO 1 Historial de Eventos

Concepto: El historial es una secuencia cronológica. Usamos una List (como ArrayList) porque necesitamos agregar elementos al final y, ocasionalmente, leer los más recientes.

Reto: Implementar el método agregarEvento(String evento).

Sugerencia: No guardes solo el texto. Para que sea útil, concatena el mensaje con la fecha y hora actual usando new java.util.Date(). Así el historial tendrá una marca de tiempo real.

TODO 2 & 3 Navegación de Alertas

Concepto: El navegador es como el botón "Atrás" y "Adelante" de un navegador web. Usamos un Deque (Double Ended Queue) porque permite manipular ambos extremos de la colección.

Retos: Implementar navegarAlSiguiente() y navegarAlAnterior().

Sugerencia: Para navegar al siguiente, puedes sacar el elemento del frente (pollFirst), devolverlo y volverlo a insertar al final (addLast). Esto crea un ciclo infinito de navegación. Haz lo mismo en sentido inverso para el método anterior.

TODO 4 & 5 Ciclo de Monitoreo

Concepto: Un ciclo de monitoreo es una cola de turnos. Usamos una Queue para asegurar que el primer sensor programado sea el primero en ser consultando (FIFO).

Reto 4: programarConsulta(String idSensor) debe evitar duplicados. Usa el método contains() antes de agregar.

Reto 5: obtenerSiguienteSensor() debe implementar la rotación: extrae el sensor del frente y agrégalo inmediatamente al final de la cola.

Sugerencia: Si la cola está vacía, el método debe retornar null para evitar que la plataforma colapse.

TODO 6, 7 & 9 Topología de Red (Grafo)

Concepto: La red de sensores es un Grafo. Usamos un Map<String, List<String>> donde la clave es el sensor y el valor es la lista de sus vecinos.

Reto 6: registrarConexion(sensorA, sensorB). Recuerda que la conexión es bidireccional: A conoce a B y B conoce a A.

Reto 7: obtenerVecinos(idSensor). Simplemente recupera la lista del mapa. Maneja el caso donde el sensor no existe usando getOrDefault().

Reto 9: detectarEstacionesAisladas(). Recorre el mapa y busca aquellas estaciones cuya lista de vecinos esté vacía.

Sugerencia: Para el Reto 6, usa computeIfAbsent. Esto crea la lista de vecinos automáticamente si es la primera vez que el sensor se registra en la red.

TODO 8 Buffer de Ingesta

Concepto: El buffer es una zona de espera. Usamos una Queue para procesar los datos en el mismo orden en que llegaron del sensor (FIFO).

Reto: Implementar procesarSiguienteLectura().

Sugerencia: Usa el método poll() de la cola. Este método es ideal porque extrae el elemento y, si la cola está vacía, retorna null sin lanzar una excepción.

TODO 10 Optimización de Memoria

Concepto: En sistemas IoT, la memoria es limitada. Un historial que crece infinitamente eventualmente causará un OutOfMemoryError.

Reto: Implementar limpiarHistorialAntiguo(int mantener).

Sugerencia: Usa un bucle while que elimine el elemento en la posición 0 mientras el tamaño de la lista sea mayor al límite permitido.
